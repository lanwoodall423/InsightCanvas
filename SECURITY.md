# Security policy

## Supported versions

Security fixes are evaluated against the current supported release for RimWorld 1.6. Older releases may not receive fixes.

## Reporting a vulnerability

Do not open a public issue for an exploitable vulnerability, credential leak, or privately reportable security problem.

Use GitHub's **Report a vulnerability** action in the repository Security tab when private vulnerability reporting is available. If that control is unavailable, contact the repository owner through the [lanwoodall423 GitHub profile](https://github.com/lanwoodall423) and request a private reporting channel. Include the affected version, reproduction steps, impact, and any proposed mitigation; do not include secrets that are not necessary to reproduce the issue.

Please allow the maintainer reasonable time to investigate before public disclosure. Do not submit game-owned proprietary assemblies or unrelated personal data in a report.
